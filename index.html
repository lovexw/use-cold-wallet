比特币冷钱包制作指南
（长期通用版）

本文是一份中性、去个人化、可长期公开使用的冷钱包制作说明文档，适合用于网站页面、项目文档或知识库。

本文不涉及价格判断、不包含投资建议，也不推广任何商业产品，仅描述被广泛验证的冷存储方法。

本文默认对象为：比特币（Bitcoin）。

目标明确且唯一：在任何情况下，让比特币私钥始终保持离线状态。

一、什么是冷钱包

冷钱包（Cold Wallet / Cold Storage）是一种私钥从生成到使用全过程不接触网络的钱包使用方式。

冷钱包不是某个特定软件，也不是某种硬件，而是一套安全原则：

  • 私钥在离线环境中生成
  • 私钥只存在于离线设备或物理介质
  • 联网设备仅用于查看余额和广播交易

只要上述原则被破坏，冷钱包即不再成立。

二、使用冷钱包前的基本原则

在开始之前，应理解以下基本共识：

  • 私钥即资产控制权
  • 助记词等同于私钥
  • 任何联网行为都会扩大攻击面

冷钱包的安全性来源于流程约束，而非个人记忆或操作习惯。

三、手机冷钱包方案（离线设备）

本方案适用于使用不再联网的旧手机作为冷端设备。

3.1 设备要求

  • Android 或 iOS 旧手机一台
  • 可彻底关闭网络功能
  • 不再用于日常通信

该设备在完成初始化后，应被视为永久离线设备。

3.2 初始化步骤（通用）

  1. 恢复出厂设置
  2. 不登录任何账号（Google / Apple ID）
  3. 不插入 SIM 卡
  4. 开启飞行模式
  5. 确认 Wi‑Fi、蓝牙、蜂窝网络均已关闭

完成以上步骤后，设备应处于完全离线状态。

3.3 生成钱包与助记词

在离线状态下：

  1. 打开已安装的钱包软件
  2. 创建新钱包
  3. 生成助记词（12 或 24 个英文单词）
助记词必须：
  • 手写记录
  • 至少备份两份
  • 不进行拍照、截图或电子存储

四、电脑冷钱包方案（双设备模型）

该方案适用于希望获得更高可验证性的用户。

4.1 设备角色划分

冷端电脑

  • 永不联网
  • 保存私钥
  • 用于离线签名

热端电脑

  • 正常联网
  • 不保存私钥
  • 用于查看余额和广播交易

4.2 冷端电脑准备

  • 全新或重装系统（Windows / macOS）
  • 禁用网络硬件
  • 通过 U 盘安装钱包软件

冷端完成初始化后，不应再次连接网络。

4.3 创建观察钱包（Watch-only）

在冷端生成钱包后：

  1. 导出主公钥（xpub）
  2. 在热端创建新钱包
  3. 使用 xpub 创建观察钱包
观察钱包具备以下特性：
  • 可生成收款地址
  • 可查看余额
  • 无法签名交易

五、离线签名与交易流程

标准冷钱包交易流程如下：

1. 热端构建
未签名交易
→
2. U盘传输
至冷端
→
3. 冷端签名
离线签名交易
→
4. 传回热端
广播至网络

整个过程中，私钥始终停留在离线环境。

六、助记词与私钥保存建议

推荐做法

  • 纸质备份
  • 分散存放
  • 防火、防水介质（如金属助记词板）

应避免的行为

  • 云端存储
  • 聊天工具传输
  • 输入至联网设备
重要提醒

任何能被复制的电子形式，都不适合存放私钥。

七、常见风险来源

冷钱包失效通常源于以下情况：

  • 离线设备重新联网
  • 私钥被拍照或数字化
  • 冷端与热端混用
  • 备份不足或集中存放

冷钱包依赖流程一致性，而非个人经验。
